⚙ Configuration requise (à faire une seule fois)
  1. Va sur console.cloud.google.com et crée un projet (gratuit).
  2. Dans le menu, ouvre API et services → Bibliothèque, cherche Gmail API et clique Activer.
  3. Va dans API et services → Écran de consentement OAuth. Choisis "Externe", remplis le nom de l'appli et ton email, puis ajoute-toi comme "utilisateur test".
  4. Va dans API et services → Identifiants → Créer des identifiants → ID client OAuth. Type d'application : Application Web.
  5. Dans "Origines JavaScript autorisées", ajoute l'adresse exacte où tu héberges ce fichier (ex : http://localhost:8000 ou https://tonnom.github.io).
  6. Copie l'ID client généré (se termine par .apps.googleusercontent.com) et colle-le ci-dessous.
